# Source provenance and notices

KhiCAS and Giac/Xcas originate with Bernard Parisse and the upstream contributors. Modified CAS sources retain their per-file notices, including GPL version 3 or later for Giac. The public snapshot includes the prepared source trees and port changes used by these builds. [Upstream calculator sources](https://www-fourier.univ-grenoble-alpes.fr/~parisse/casio/giac35.tar.bz2) · [Upstream calculator directory](https://www-fourier.univ-grenoble-alpes.fr/~parisse/casio/).

The loader project sources taken from FX Universal Loader retain [the upstream project license](licenses/Loader-MIT.txt). gint-derived runtime portions retain the [gint notice](licenses/gint-NOTICE.txt). The [GPL text](licenses/COPYING3) and [GCC Runtime Library Exception](licenses/COPYING.RUNTIME) accompany the relevant upstream components. TomMath, TinyMT and the math and C/C++ runtime components retain their individual upstream terms. Project source, upstream software and runtime components retain their respective licenses.

Source locations for this release include the Git source checkout, the giac-source-and-relink-inputs.tar.gz attachment, and the [SDK/toolchain source companion](https://github.com/lilith-is-all-you-need/fx-9860giii-sdk/releases/tag/v0.2.0-r2) for GCC 14.1.0, binutils, gint, fxlibc and OpenLibm. The snapshot's prepared Giac trees carry the local math modifications. support contains the runtime preparation and historical patch scripts. The original 2,094,444-byte input is identified by hash and supplied by the tester from the original distribution. Firmware and proprietary Casio development kits are external to this repository.
