KhiCAS 二维显示候选 RC2 — 2026-11-17
目标：fx-9860GIII，用户 OS 03.70.0200。本版通过电脑与模拟器检查，尚待本版实机验证。

安装
把本包 KhiMap.g1a 和 KHICAS.BIN 一起放到计算器存储根目录，替换旧的同名文件。
两份文件必须来自同一个包；不可只换 BIN 或只换 G1A。原 RC1 已保留，可成对替换回退。
只需复制这两个文件，其余文档供电脑阅读。不需要另放早期 LIB 探针或测试程序。

使用
主标题已去掉 BASE02。输入下方默认二维预览，原有文字输入按键保持不变。
F6 Options → Input 2D 可开关输入预览；Output 可切换输出二维/文本，默认二维。
选中条目按 EXE 切换、EXIT 返回。重新启动后恢复默认开启。
F3 查看输入/结果；若结果为图形，F3 仍进入图形。
长或高的结果自动打开查看器。方向键横纵滚动，SHIFT+方向键大步滚动，EXE 回到左上。
F1 在二维与完整文本之间切换，EXIT/F3 返回。箭头表示还有内容可滚动。
无法排版的内容完整回退文本，左右翻页/上下逐行。矩阵目前保留括号行文。

建议本次重点验证
1. 输入 1/2，检查输入预览和结果的分式；再试 sqrt((x^2+1)/(x-1))。
2. expand((x+1)^8)，检查自动展开、左右滚动到末尾，以及 F1 文本切换。
3. F6 中切换输入/输出选项，并确认 solve、simplify、积分及绘图保持可用。
4. EXIT 返回后直接重新打开，检查仍能计算。

边界
突破的是原大 G1A 的装载/映射路径，物理 RAM 没有增加。大程序在 Flash，按需建立映射执行。
本版继续使用计算器 Giac 分支，不含 Python；不能将定向验证等同于全部 CAS 路径已充分验证。
输入及结果长度仍受原缓冲限制，超过上限会明确报错。二维预览不会执行表达式或修改变量。
具体内核改动、内存预算和验证范围见“技术与验证说明.md”和 VALIDATION.json。
